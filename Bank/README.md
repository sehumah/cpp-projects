# Bank

Bank is a C++ console project that simulates banking operations:

- Opening & closing accounts
- Deposit
- Withdrawal
- Account-to-account money transfer
- Bank loan

More features will be implemented regularly.

##

To run the program, first compile it with:

```bash
g++ -std=c++20 {Account,Bank,main}.cpp -o a.out
```

then you can run the generated executable file with:

```bash
./a.out
```

## Version History

__Version 1__ has the following features:

- opening accounts
- depositing money
- withdrawing money
- transfering money
- getting a bank loan
- viewing accounts
- closing accounts
- a CSV file to keep track of all accounts
